# maxkle1nz/homebrew-tap

Homebrew formulae for tools by [Max Kle1nz](https://github.com/maxkle1nz) at DEViance Intelligence.

```sh
brew install maxkle1nz/tap/agy
```

| Formula | Tool |
|---|---|
| `agy` | [Wingman AGY](https://github.com/maxkle1nz/wingman-agy): a command-line bridge to Google Antigravity agents and the Gemini API |
